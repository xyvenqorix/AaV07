🎮 Acerca de Game Boy Web

Game Boy Web es un emulador basado en navegador diseñado para disfrutar juegos de Game Boy directamente desde la página web.

No necesitas instalar una aplicación adicional. Selecciona un juego y pulsa JUGAR para iniciar el emulador.

Emulador: EmulatorJS

Sistema: Nintendo Game Boy

Desarrollado por: xyvenqorix
